# 1. UNDERSTAND THE BUSINESS MODEL

VELORA MOTION STUDIO helps brands and businesses create professional marketing videos and advertisements using advanced AI production workflows. Clients do not need to arrange expensive video shoots, cameras, production teams, models, locations, or complicated filming arrangements.

The client simply provides:

- Raw video footage.
- Product photographs.
- Product images from different angles.
- Brand assets and logos.
- Existing advertisements or visual references.
- Product information and marketing objectives.
- Optional scripts, voiceovers, and brand guidelines.

We handle the entire creative production process, including:

1. Creative concept development.
2. Advertising strategy.
3. AI-assisted video production.
4. Cinematic scene creation.
5. Product visualization.
6. AI-generated environments and backgrounds.
7. AI actors and models where appropriate.
8. Voiceovers and sound design.
9. Professional editing.
10. Color grading.
11. Motion graphics.
12. Final advertising-ready video delivery.

Core message: **You provide the product. We create the advertisement. No traditional production shoot required.** The website must communicate this business model within the first few seconds of visiting.

# 22. TECHNICAL ARCHITECTURE

Modern, maintainable stack. Preferred where compatible: React, TypeScript, Next.js or appropriate React framework, Tailwind CSS, Framer Motion, Supabase (auth + database), Supabase Storage or equivalent secure object storage, server-side APIs or server actions. Preserve an existing suitable stack rather than migrating unnecessarily.

Database tables: admin users and roles; portfolio projects; portfolio categories; services; pricing packages; client inquiries; uploaded media metadata; testimonials; FAQs; website content; global settings. Appropriate relationships, timestamps, validation, indexes.

Security: secure authentication; protected admin routes; database Row Level Security; server-side authorization; input validation; upload type/size restrictions; safe file handling; rate limiting on public forms; spam protection; secure environment variables. Never expose private API keys or service-role credentials in frontend code. Never trust frontend-only admin permissions.

# 23. RESPONSIVE DESIGN AND PERFORMANCE

Perfect across desktop, laptop, tablet, mobile. Mobile must not feel like a compressed desktop version — dedicated mobile layout. Optimize video playback, image delivery, font loading, JS bundles, animation performance, lazy loading, caching. Responsive video strategy with mobile-optimized alternatives. Excellent Core Web Vitals / Lighthouse. Do not sacrifice accessibility or performance for decorative effects.

# 24. SEO AND BUSINESS DISCOVERABILITY
